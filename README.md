# 🚀 ApexPlanet Task 2 - Smart Contact & Task Manager

A modern and responsive web application developed as part of the **ApexPlanet Software Pvt. Ltd. Web Development Internship – Task 2**.

This project demonstrates intermediate-level **HTML, CSS, and JavaScript** concepts, including form validation, responsive layouts, CSS Grid, Flexbox, and JavaScript DOM manipulation.

---

## 📌 Project Overview

The **Smart Contact & Task Manager** is a responsive frontend web application that combines a validated contact form with a dynamic task management system.

The project was created to strengthen practical knowledge of:

- HTML form development
- CSS styling and responsive layouts
- Flexbox and CSS Grid
- JavaScript form validation
- DOM manipulation
- Dynamic element creation
- Event handling

---

### 📩 Contact Form

- Full Name input
